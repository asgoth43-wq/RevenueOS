# Marketplace workflow

1. Generate the product with `/generator/product`.
2. Generate SEO metadata with `/seo/generate`.
3. Generate a marketplace-ready listing with `/marketplace/listing`.
4. Generate a tracked destination URL with `/marketplace/tracking`.
5. Manually publish the listing on the chosen marketplace and follow its terms.

RevenueOS does not automatically create third-party accounts or publish listings without explicit user authorization and a supported integration.
