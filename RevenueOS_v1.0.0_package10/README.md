# RevenueOS v1.0.0

RevenueOS provides a lightweight foundation for digital-product generation,
marketplace listing preparation, affiliate-link management and performance
reporting.

## Release checklist
1. Configure environment variables.
2. Install project dependencies.
3. Run database migrations if the project uses migrations.
4. Start the API.
5. Create your own marketplace and affiliate accounts.
6. Add only URLs you are authorized to use.
7. Run the test suite.
8. Verify generation, export, tracking and dashboard endpoints.

RevenueOS does not create third-party accounts or publish externally without
an explicit supported integration and authorization.
