# RevenueOS 1.0 release

## Pre-release checklist

- Set a strong `SECRET_KEY`.
- Configure `DATABASE_URL`.
- Configure `CORS_ORIGINS`.
- Run the complete test suite.
- Review authentication and ownership checks.
- Review marketplace and affiliate URLs.
- Confirm backups and error logging before production use.

## Legal and operational

The owner must independently register with marketplaces and affiliate
programs, accept their terms, and comply with applicable tax, consumer
protection, advertising and affiliate-disclosure requirements.

Do not automate account creation, identity verification, or actions that
violate a platform's terms.
